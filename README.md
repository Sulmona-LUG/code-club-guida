# Code Club Sulmona · Guida del volontario

La guida per i mentor volontari del **Code Club Sulmona**, il club di coding per bambini e
ragazzi dai 7 ai 14 anni al Blink HUB di Sulmona, in collaborazione con il
[Sulmona LUG](https://www.sulmonalug.it/).

**Consultala online: <https://sulmonalug.it/code-club-guida/>**

La mappa pubblica dell'Arcipelago, per famiglie e scuole, è su
<https://www.sulmonalug.it/code-club/arcipelago/>.

## Contenuti

| Percorso | Cosa contiene |
|---|---|
| [`guida-mentor.md`](guida-mentor.md) | La guida del mentor: l'Arcipelago, i gradi, le isole, le missioni annuali, i materiali |
| [`schede/`](schede/) | Le schede attività di ogni isola, grado per grado |
| [`grafica/`](grafica/) | Logo, stemma, timbri (anche SVG), diario di bordo, calendario dell'esploratore |

## Provare il sito in locale

Serve Ruby con Bundler:

```sh
bundle install
bundle exec jekyll serve
```

poi apri <http://localhost:4000/code-club-guida/>. Il sito viene pubblicato su GitHub Pages
automaticamente a ogni push su `main` (vedi `.github/workflows/pages.yml`).
